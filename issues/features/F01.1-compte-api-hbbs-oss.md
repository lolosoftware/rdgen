# ✨ F01.1 – Compatibilité du compte API avec hbbs OSS

## Contexte

Un client connecté à une API tierce possède un jeton de compte. RustDesk tente de protéger ce jeton par un échange `secure_tcp` que le serveur officiel OSS ne met pas en œuvre, ce qui bloque la mise en relation.

## User story

En tant qu'administrateur d'un serveur RustDesk OSS, je veux conserver la session de compte API sans transmettre son jeton à `hbbs` afin d'utiliser le carnet d'adresses et d'établir les connexions distantes.
