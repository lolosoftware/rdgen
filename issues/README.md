# Backlog rdgen

Les artefacts de produit sont organisés par niveau :

- `epics/` : domaines techniques ou fonctionnels larges ;
- `features/` : capacités livrables ;
- `tasks/` : unités concrètes de réalisation.

Les relations parent-enfant et les dépendances sont déclarées dans chaque fichier. Les identifiants sont uniques dans ce dépôt.
